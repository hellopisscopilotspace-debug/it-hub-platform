# IT Hub — Public Edition

IT Hub is a next-generation intent-based development platform.  
You write what you want — the system generates the logic, the code, and the explanation.

This repository contains the **public open-source version** of the platform.

---

## 🚀 Core Features

- **Intent Engine**  
  Basic endpoint to receive user intent and return a normalized representation.

- **Simple Language Detection (Placeholder)**  
  Very naive language detection to be replaced with a real model later.

- **FastAPI Backend**  
  Lightweight, async-ready Python backend.
